เครื่องมือแปลภาษาแบบเรียลไทม์สำหรับ VRChat

แปลเสียงหรือข้อความ และส่งผลลัพธ์ไปยัง VRChat Chatbox โดยอัตโนมัติ
เป็นแอปเดสก์ท็อปที่ช่วยให้การสื่อสารกับเพื่อนต่างชาติ การจัดอีเวนต์ และการพูดคุยหลายภาษาเป็นไปอย่างราบรื่น

✨ ฟีเจอร์หลัก

  • แปลเสียงแบบเรียลไทม์
  • ส่งไปยัง VRChat Chatbox อัตโนมัติ
  • แปลข้อความที่พิมพ์
  • รองรับ 20 ภาษา
  • การแปลแบบเป็นธรรมชาติ (โหมด ChatGPT)
  • ฟังก์ชันแบล็คลิสต์เพื่อลดความผิดพลาดของการรู้จำเสียง

🆕 อัปเดต v1.9.26 → v1.11.1

✨ ฟีเจอร์ใหม่

  • เพิ่มฟีเจอร์ “ส่งข้อความต้นฉบับไปยังแบล็คลิสต์” แบบคลิกเดียว
  • ปรับปรุงการแปลแบบเป็นธรรมชาติ (โหมด ChatGPT)
  • รองรับ tooltip หลายภาษา

🧹 การปรับปรุงแบล็คลิสต์

  • เปลี่ยนระบบแก้ไขเป็นแบบ “อัปเดต” เพื่อความปลอดภัย
  • เสริมรายการแบล็คลิสต์เริ่มต้น
  • ปรับปรุงการกรองเสียงรบกวนและข้อผิดพลาด

🌍 UI และการรองรับหลายภาษา

  • UI รองรับ 5 ภาษา: ญี่ปุ่น / อังกฤษ / จีนตัวย่อ / จีนตัวเต็ม / เกาหลี
  • แก้ไขการเชื่อมโยงหลายภาษาในหน้าต่าง License และ Guide
  • ปรับปรุงความเสถียรในการสลับภาษา

🎨 การปรับปรุง UI

  • จัดระเบียบเมนูด้านบนใหม่
  • ปรับตำแหน่ง README / Update / License
  • ปรับปรุงอินเทอร์เฟซการป้อนข้อมูลและการใช้งาน
  • ปรับปรุงการแสดง tooltip

⚙️ ความเสถียรและการปรับปรุงภายใน

  • แก้ไขบั๊กเล็กน้อย
  • ปรับปรุงความเสถียรโดยรวม
  • ปรับปรุงกระบวนการแปล

▶️ วิธีใช้งานพื้นฐาน

การแปลเสียง

  1. เปิดแอป
  2. เลือกไมโครโฟน
  3. ตั้งค่าภาษาอินพุตและภาษาเป้าหมาย
  4. กดปุ่ม Start

การแปลข้อความ

  1. พิมพ์ข้อความในช่อง “Original” ด้านล่าง
  2. กด Enter เพื่อแปลและส่ง

Enter: ส่ง
Shift + Enter: ขึ้นบรรทัดใหม่

🤖 การแปลแบบเป็นธรรมชาติ (โหมด ChatGPT)

ให้การแปลที่เป็นธรรมชาติยิ่งขึ้นและปรับโทนภาษา

  • สำนวนที่นุ่มนวลขึ้น
  • ประโยคสั้นเหมาะกับการสนทนา
  • ปรับความหมายให้เป็นธรรมชาติ

ต้องใช้ OpenAI API Key และมีค่าใช้จ่ายตามการใช้งาน

🧹 ฟังก์ชันแบล็คลิสต์

การรู้จำเสียงอาจแสดงข้อความที่ไม่ได้พูดจริง
เช่น ประโยคปิดวิดีโอ เสียงรบกวน หรือการรู้จำผิด

ข้อความที่เพิ่มในแบล็คลิสต์จะไม่ถูกส่งโดยอัตโนมัติ

วิธีใช้

  • ใช้ปุ่ม “ส่งข้อความต้นฉบับไปยังแบล็คลิสต์” เพื่อเพิ่มทันที
  • แก้ไขใน Advanced Settings แล้วกด “Update Blacklist” เพื่อบันทึก

หมายเหตุ

  • หากเพิ่มมากเกินไป อาจกรองบทสนทนาปกติด้วย
  • แนะนำให้ใช้วลีสั้น ๆ

💻 ความต้องการของระบบ

  • Windows
  • VRChat (เวอร์ชัน PC)
  • เปิดใช้งาน OSC
  • ไมโครโฟน
  • การเชื่อมต่ออินเทอร์เน็ต

ไม่รองรับ Quest แบบ standalone
