เครื่องมือแปลภาษาแบบเรียลไทม์สำหรับ VRChat

แปลเสียงพูดหรือข้อความของคุณ และส่งไปยัง Chatbox ของ VRChat โดยอัตโนมัติ ช่วยให้การสื่อสารกับเพื่อนจากต่างประเทศเป็นธรรมชาติมากขึ้น

✨ ฟังก์ชันหลัก

  • แปลเสียงพูดแบบเรียลไทม์
  • ส่งไปยัง VRChat Chatbox อัตโนมัติ
  • แปลจากการพิมพ์ข้อความ
  • รองรับหลายภาษา
  • โหมดแปลด้วย ChatGPT
  • ระบบ Blacklist ลดการรู้จำผิดพลาด

🆕 การปรับปรุงล่าสุด

ปรับปรุงการใช้งานจริง

  • ปรับปรุงรายการเริ่มต้นของ Blacklist
  • แก้ไขข้อผิดพลาดเล็กน้อย
  • เพิ่มความเสถียรโดยรวม

▶️ วิธีใช้งานพื้นฐาน

การแปลด้วยเสียง

  1. เปิดแอปพลิเคชัน
  2. เลือกไมโครโฟน
  3. ตั้งค่าภาษาต้นทางและภาษาปลายทาง
  4. กด “เริ่ม”

เมื่อคุณพูด ระบบจะแปลอัตโนมัติและส่งไปยัง VRChat Chatbox

การแปลด้วยข้อความ

  1. พิมพ์ลงในช่อง “ข้อความต้นฉบับ” ด้านล่าง
  2. กด Enter เพื่อแปลและส่ง

Enter: ส่ง
Shift + Enter: ขึ้นบรรทัดใหม่

🎤 ลำดับความสำคัญระหว่างเสียงและการพิมพ์

ในการตั้งค่าขั้นสูง สามารถสลับลำดับความสำคัญระหว่างการพูดและการพิมพ์ได้ ผ่านตัวเลือก “เขียนทับด้วยเสียงระหว่างพิมพ์ข้อความ”

  • ON: รับเสียงพูดแม้ขณะกำลังพิมพ์
  • OFF: ระหว่างพิมพ์จะไม่รับเสียงพูด และให้ความสำคัญกับข้อความที่พิมพ์

หากต้องการความแม่นยำ เช่น ใช้ดำเนินรายการกิจกรรม แนะนำให้ปิดการเขียนทับด้วยเสียง แล้วใช้การพิมพ์แทน

🤖 เกี่ยวกับการแปลด้วย ChatGPT

เมื่อใช้โหมดแปลด้วย ChatGPT จะได้ประโยคสนทนาที่เป็นธรรมชาติมากขึ้น

  • ถ้อยคำสุภาพและนุ่มนวลขึ้น
  • ประโยคสั้นเหมาะกับการสนทนา
  • ปรับอารมณ์และความหมายได้เป็นธรรมชาติ

ต้องใช้ OpenAI API Key และมีค่าใช้จ่ายตามการใช้งาน

💰 ค่าใช้จ่าย OpenAI API

  • OpenAI API คิดค่าบริการตามการใช้งาน
  • จ่ายเฉพาะส่วนที่ใช้จริง
  • หากเปิด Pay-as-you-go จะมีการคิดค่าบริการต่อเนื่องตามการใช้งาน
  • แนะนำให้ตั้ง Usage limit เพื่อป้องกันการใช้เกินจำเป็น
  • แนะนำตั้งวงเงินประมาณ 5–10 ดอลลาร์
  • 10 ดอลลาร์สามารถแปลข้อความสนทนาทั่วไปได้ประมาณ 100,000–300,000 ครั้ง

🚫 ระบบ Blacklist

บางครั้งระบบรู้จำเสียงอาจแสดงข้อความที่คุณไม่ได้พูด หากเพิ่มข้อความนั้นลงใน Blacklist จะช่วยลดโอกาสการส่งข้อความเดิมอีกครั้ง

💻 ความต้องการของระบบ

  • Windows
  • VRChat เวอร์ชัน PC
  • เปิดใช้งาน OSC
  • ไมโครโฟน
  • การเชื่อมต่ออินเทอร์เน็ต

ไม่สามารถใช้งานบน Quest แบบเดี่ยวได้

⚠️ ข้อควรทราบ

  • โหมด ChatGPT มีค่าใช้จ่ายตามการใช้งาน
  • Whisper model จะดาวน์โหลดครั้งแรกเมื่อใช้งาน
  • โมเดลความแม่นยำสูงใช้ทรัพยากรคอมพิวเตอร์มากขึ้น
  • แนะนำให้เปลี่ยนค่าต่าง ๆ ขณะหยุดการทำงาน

🔄 วิธีอัปเดต

ปัจจุบันเป็นการอัปเดตแบบ manual

  • เวอร์ชัน ZIP: เขียนทับไฟล์เดิม
  • เวอร์ชันติดตั้ง: ติดตั้งใหม่

สามารถตรวจสอบเวอร์ชันล่าสุดได้จากหน้าดาวน์โหลด หรือปุ่มอัปเดตภายในแอป
