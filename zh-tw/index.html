✨ VRC Misa Translator v1.10.8

VRChat 用即時翻譯工具

VRC Misa Translator 是一款桌面應用程式，可以將麥克風語音或手動輸入的文字翻譯後， 傳送到 VRChat 的 Chatbox。

適合用於和海外朋友聊天、活動主持、多語言交流等情境。

🚀 主要功能

🎤 語音翻譯

  • 使用 Whisper 進行即時語音辨識
  • 支援 14 種語言
  • 支援 Google 翻譯 / ChatGPT 翻譯模式
  • 可選擇輕量模型到高精度模型

⌨️ 文字輸入翻譯

  • 可直接在原文輸入框中輸入文字
  • 按 Enter 即可翻譯並送出
  • Shift + Enter 可換行
  • 送出後自動清空文字
  • 手動輸入時會顯示鉛筆圖示

📡 VRChat 連動

  • 透過 OSC 將翻譯文字傳送到 VRChat Chatbox
  • 支援自動傳送
  • 協助多語言交流

⚙️ UI 與便利功能

  • 翻譯預設模式（標準 / 快速 / 高品質）
  • 麥克風列表更新

  • 日誌顯示與篩選
  • UI 語言切換（日文 / English）

▶️ 基本使用方法

  1. 啟動應用程式
  2. 選擇麥克風
  3. 設定輸入語言與翻譯目標語言
  4. 按下「開始」

對著麥克風說話後，翻譯文字會自動傳送到 VRChat Chatbox。

文字輸入

  1. 在原文輸入框中輸入文字
  2. 按 Enter 翻譯並送出

Enter = 送出
Shift + Enter = 換行

🎤 輸入文字時的語音覆蓋

在進階設定中，可以切換麥克風語音輸入與手動文字輸入的優先順序。

  • ON：輸入文字時，語音輸入仍可覆蓋內容
  • OFF：手動輸入優先，輸入中會忽略語音輸入

如果正在主持活動，或需要更準確的翻譯，建議關閉此功能並使用手動輸入。

🤖 ChatGPT 翻譯

使用 ChatGPT 翻譯模式，可以讓翻譯內容更自然、更接近日常對話。

  • 更柔和的語氣
  • 適合 VRChat 的短句表達
  • 自然的語感調整

需要 OpenAI API Key。ChatGPT 翻譯採用按量計費。

💻 系統需求

  • Windows PC
  • VRChat PC 版
  • 啟用 OSC
  • 麥克風
  • 網路連線

無法在 Quest 單機模式下使用。
