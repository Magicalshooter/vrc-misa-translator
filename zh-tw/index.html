▶️ 基本使用方式

語音翻譯

  1. 啟動應用程式
  2. 選擇麥克風
  3. 設定輸入語言與翻譯目標語言
  4. 按下開始按鈕

文字輸入翻譯

  1. 在下方「原文」欄位輸入文字
  2. 按 Enter 翻譯並送出

Enter：送出
Shift + Enter：換行

🤖 關於 ChatGPT 翻譯

使用 ChatGPT 翻譯模式，可讓對話內容更自然。

  • 更柔和的表達方式
  • 適合對話的短句
  • 自然的語氣調整

需要 OpenAI API 金鑰。ChatGPT 翻譯依使用量計費。
