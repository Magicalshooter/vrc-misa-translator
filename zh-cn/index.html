VRC Misa Translator

VRChat 实时翻译工具

将语音或文本实时翻译，并自动发送到 VRChat Chatbox。
这是一款让与海外朋友交流、活动主持、多语言沟通更加顺畅的桌面应用程序。

  • 自动发送至 VRChat Chatbox

  • 支持 20 种语言
  • 自然翻译（ChatGPT 模式）
  • 减少误识别的黑名单功能

▶️ 基本使用方法

语音翻译

  1. 启动应用程序
  2. 选择麦克风
  3. 设置输入语言和目标语言
  4. 点击开始按钮

文本输入翻译

  1. 在下方“原文”输入框中输入文本
  2. 按 Enter 进行翻译并发送

Enter：发送
Shift + Enter：换行

🤖 自然翻译（ChatGPT 模式）

提供更自然的翻译和语气调整。

  • 更柔和的表达方式
  • 适合对话的短句
  • 自然的语气与细节调整

需要 OpenAI API Key，按使用量收费。

🧹 黑名单功能

语音识别有时会生成并未实际说出的内容。
（例如视频结尾语、噪音或误识别文本）

添加到黑名单的文本将不会被自动发送。

使用方法

  • 使用“一键将原文加入黑名单”按钮快速添加
  • 在高级设置中手动编辑后点击“更新黑名单”保存

注意事项

  • 添加过多可能会过滤正常对话
  • 建议以短语为单位添加

💻 系统需求

  • Windows
  • VRChat（PC 版）
  • 已启用 OSC
  • 麦克风
  • 互联网连接

不支持 Quest 单机运行。
