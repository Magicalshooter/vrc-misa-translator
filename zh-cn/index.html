VRC Misa Translator

VRChat 实时翻译工具

可翻译语音或输入文本，并自动发送到 VRChat Chatbox。
这是一款让海外好友交流、活动主持、多语言沟通更加顺畅的桌面应用程序。

  • 自动发送到 VRChat Chatbox
  • 文本输入翻译
  • 支持 20 种语言
  • ChatGPT 翻译模式
  • 减少误识别的黑名单功能

▶️ 基本使用方法

语音翻译

  1. 启动应用程序
  2. 选择麦克风
  3. 设置输入语言与目标语言
  4. 点击开始按钮

文本输入翻译

  1. 在下方“原文”栏输入文字
  2. 按 Enter 翻译并发送

Enter：发送
Shift + Enter：换行

🤖 关于 ChatGPT 翻译

使用 ChatGPT 翻译模式，可让对话内容更加自然。

  • 更柔和的表达方式
  • 适合对话的短句
  • 自然的语气调整

需要 OpenAI API Key。ChatGPT 翻译按使用量计费。

💻 系统需求

  • Windows
  • VRChat（PC版）
  • 已启用 OSC
  • 麦克风
  • 网络连接

Quest 单机模式无法使用。
