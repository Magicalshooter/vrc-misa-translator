VRChat 实时翻译工具

VRC Misa Translator 是一款桌面应用程序，可以将麦克风语音或手动输入的文字翻译后， 发送到 VRChat 的 Chatbox。

适合用于与海外朋友聊天、活动主持、多语言交流等场景。

🚀 主要功能

🎤 语音翻译

  • 使用 Whisper 进行实时语音识别
  • 支持 14 种语言
  • 支持 Google 翻译 / ChatGPT 翻译模式
  • 可选择轻量模型到高精度模型

⌨️ 文本输入翻译

  • 可直接在原文输入框中输入文字
  • 按 Enter 即可翻译并发送
  • Shift + Enter 可换行
  • 发送后自动清空文字
  • 手动输入时会显示铅笔图标

📡 VRChat 联动

  • 通过 OSC 将翻译文字发送到 VRChat Chatbox
  • 支持自动发送
  • 帮助进行多语言交流

⚙️ UI 与便利功能

  • 翻译预设模式（标准 / 快速 / 高质量）
  • 麦克风列表更新

▶️ 基本使用方法

  1. 启动应用程序
  2. 选择麦克风
  3. 设置输入语言与翻译目标语言
  4. 点击“开始”

对着麦克风说话后，翻译文字会自动发送到 VRChat Chatbox。

文本输入

  1. 在原文输入框中输入文字
  2. 按 Enter 翻译并发送

Enter = 发送
Shift + Enter = 换行

🎤 输入文字时的语音覆盖

在高级设置中，可以切换麦克风语音输入与手动文本输入的优先顺序。

  • ON：输入文字时，语音输入仍可覆盖内容
  • OFF：手动输入优先，输入中会忽略语音输入

如果正在主持活动，或需要更准确的翻译，建议关闭此功能并使用手动输入。

🤖 ChatGPT 翻译

使用 ChatGPT 翻译模式，可以让翻译内容更自然、更接近日常对话。

  • 更柔和的语气
  • 适合 VRChat 的短句表达
  • 自然的语感调整

需要 OpenAI API Key。ChatGPT 翻译采用按量计费。

💻 系统需求

  • Windows PC
  • VRChat PC 版
  • 启用 OSC
  • 麦克风
  • 网络连接

无法在 Quest 单机模式下使用。
