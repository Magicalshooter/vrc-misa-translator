VRC Misa Translator

VRChat용 실시간 번역 도구

음성 또는 입력한 텍스트를 번역하여 VRChat Chatbox로 자동 전송합니다.
해외 친구와의 대화, 이벤트 진행, 다국어 소통을 더욱 편하게 만들어 주는 데스크톱 앱입니다.

✨ 주요 기능

  • 실시간 음성 번역
  • VRChat Chatbox 자동 전송
  • 텍스트 입력 번역
  • 20개 언어 지원
  • ChatGPT 번역 모드
  • 오인식을 줄이는 블랙리스트 기능

🆕 최근 개선 사항

UI 개선

  • 상단 메뉴 정리
  • README / 업데이트 / 라이선스 배치 개선
  • 고부하 모델 경고 창 개선
  • 업데이트 페이지 표시 오류 수정

사용성 향상

  • 텍스트 입력 기능 개선
  • 입력 상태 표시 개선
  • UI 언어 전환 안정성 향상
  • 라이선스 버튼 다국어 연동 수정

실용성 개선

  • 블랙리스트 기본 내용 강화
  • 세부 버그 수정
  • 전체 안정성 향상

▶️ 기본 사용 방법

음성 번역

  1. 앱 실행
  2. 마이크 선택
  3. 입력 언어와 번역 언어 설정
  4. 시작 버튼 클릭

텍스트 입력 번역

  1. 하단 “원문” 입력란에 텍스트 입력
  2. Enter 키로 번역 및 전송

Enter: 전송
Shift + Enter: 줄바꿈

🤖 ChatGPT 번역에 대하여

ChatGPT 번역 모드를 사용하면 더 자연스러운 대화문을 만들 수 있습니다.

  • 부드러운 표현
  • 대화에 적합한 짧은 문장
  • 자연스러운 뉘앙스 조정

OpenAI API Key가 필요합니다. ChatGPT 번역은 사용량 기반 과금입니다.

💻 시스템 요구 사항

  • Windows
  • VRChat (PC 버전)
  • OSC 활성화
  • 마이크
  • 인터넷 연결

Quest 단독 환경에서는 사용할 수 없습니다.
