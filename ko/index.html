VRC Misa Translator

VRChat용 실시간 번역 도구

음성이나 텍스트를 실시간으로 번역하여 VRChat Chatbox로 자동 전송합니다.
해외 친구와의 대화, 이벤트 진행, 다국어 커뮤니케이션을 더 원활하게 만드는 데스크톱 앱입니다.

✨ 주요 기능

  • 실시간 음성 번역
  • VRChat Chatbox 자동 전송
  • 텍스트 입력 번역
  • 20개 언어 지원
  • 자연스러운 번역 (ChatGPT 모드)
  • 오인식을 줄이는 블랙리스트 기능

🆕 v1.9.26 → v1.11.1 업데이트

✨ 신규 기능

  • “원문을 블랙리스트로 보내기” 원클릭 기능 추가
  • 자연스러운 번역 (ChatGPT 모드) 개선

  • 번역 처리 개선

▶️ 기본 사용 방법

음성 번역

  1. 앱 실행
  2. 마이크 선택
  3. 입력 언어 및 번역 언어 설정
  4. 시작 버튼 클릭

텍스트 입력 번역

  1. 하단 “원문” 입력란에 텍스트 입력
  2. Enter 키로 번역 및 전송

Enter: 전송
Shift + Enter: 줄바꿈

🤖 자연스러운 번역 (ChatGPT 모드)

더 자연스러운 번역과 문체 조정을 제공합니다.

  • 부드러운 표현
  • 대화에 적합한 문장
  • 자연스러운 뉘앙스 조정

OpenAI API 키가 필요하며 사용량 기반 과금이 적용됩니다.

🧹 블랙리스트 기능

음성 인식은 실제로 말하지 않은 문장을 표시할 수 있습니다.
(예: 영상 종료 멘트, 노이즈, 오인식 등)

블랙리스트에 등록된 문장은 자동 전송되지 않습니다.

사용 방법

  • “원문을 블랙리스트로 보내기” 버튼으로 즉시 등록
  • 상세 설정에서 편집 후 “블랙리스트 업데이트”로 저장

주의 사항

  • 너무 많이 등록하면 정상 대화도 필터링될 수 있습니다
  • 짧은 문장 단위로 등록하는 것을 권장합니다

💻 시스템 요구사항

  • Windows
  • VRChat (PC 버전)
  • OSC 활성화
  • 마이크
  • 인터넷 연결

Quest 단독에서는 사용할 수 없습니다.
