✨ VRC Misa Translator v1.10.8

VRChat용 실시간 번역 도구

VRC Misa Translator는 마이크 음성 또는 직접 입력한 텍스트를 번역하여 VRChat Chatbox로 전송할 수 있는 데스크톱 애플리케이션입니다.

해외 친구와의 대화, 이벤트 진행, 다국어 커뮤니케이션에 적합합니다.

🚀 주요 기능

🎤 음성 번역

  • Whisper 기반 실시간 음성 인식
  • 14개 언어 지원
  • Google 번역 / ChatGPT 번역 모드 지원
  • 경량 모델부터 고정밀 모델까지 선택 가능

⌨️ 텍스트 입력 번역

  • 원문 입력창에 직접 입력 가능
  • Enter 키로 번역 및 전송
  • Shift + Enter 줄바꿈
  • 전송 후 자동으로 입력 내용 삭제
  • 수동 입력 시 연필 아이콘 표시

📡 VRChat 연동

  • OSC를 통해 VRChat Chatbox로 전송
  • 자동 전송 지원
  • 다국어 커뮤니케이션 지원

⚙️ UI 및 편의 기능

  • 프리셋 모드 (표준 / 빠름 / 고품질)
  • 마이크 목록 새로고침
  • 오인식 블랙리스트 기능
  • 로그 표시 및 필터
  • UI 언어 전환 (일본어 / English)
  • README 버튼
  • 업데이트 페이지 버튼
  • 라이선스 보기

💰 ChatGPT 사용량 관리

  • 오늘의 사용 금액 표시
  • 사용 기록 확인
  • 사용량 경고 기능

▶️ 기본 사용 방법

  1. 앱 실행
  2. 마이크 선택
  3. 입력 언어와 번역 대상 언어 설정
  4. 시작 버튼 클릭

마이크에 말하면 번역된 텍스트가 자동으로 VRChat Chatbox로 전송됩니다.

텍스트 입력

  1. 원문 입력창에 텍스트 입력
  2. Enter 키로 번역 및 전송

Enter = 전송
Shift + Enter = 줄바꿈

🎤 입력 중 음성 덮어쓰기

고급 설정에서 음성 입력과 수동 입력 중 어떤 입력을 우선할지 선택할 수 있습니다.

  • ON: 입력 중에도 음성이 텍스트를 덮어쓸 수 있습니다
  • OFF: 수동 입력이 우선되며 입력 중 음성은 무시됩니다

이벤트 진행이나 정확한 번역이 필요한 경우 OFF를 권장합니다.

🤖 ChatGPT 번역

ChatGPT 번역 모드를 사용하면 보다 자연스럽고 대화체에 가까운 번역이 가능합니다.

  • 부드러운 표현
  • VRChat에 적합한 짧은 문장
  • 자연스러운 어조 조정

OpenAI API Key가 필요합니다. 사용량 기반 과금입니다.

💻 시스템 요구 사항

  • Windows PC
  • VRChat PC 버전
  • OSC 활성화

앱 내 업데이트 버튼 또는 다운로드 페이지에서 최신 버전을 확인할 수 있습니다.
