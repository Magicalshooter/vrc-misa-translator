✨ VRC Misa Translator v1.10.8

Outil de traduction en temps réel pour VRChat

VRC Misa Translator est une application de bureau qui traduit votre voix ou le texte saisi manuellement, puis l’envoie dans le Chatbox de VRChat.

Elle est conçue pour faciliter les conversations avec des utilisateurs du monde entier, l’animation d’événements et la communication multilingue.

▶️ Utilisation de base

Traduction vocale

  1. Lancez l’application
  2. Sélectionnez votre microphone
  3. Choisissez la langue d’entrée et la langue de traduction
  4. Cliquez sur Démarrer

Lorsque vous parlez, le texte traduit est envoyé automatiquement au Chatbox de VRChat.

Saisie texte

  1. Saisissez votre texte dans le champ source
  2. Appuyez sur Entrée pour traduire et envoyer

Entrée = envoyer
Maj + Entrée = nouvelle ligne

🎤 Priorité entre voix et saisie manuelle

Dans les paramètres avancés, vous pouvez choisir la priorité entre l’entrée vocale et la saisie manuelle.

  • ON : la voix peut remplacer le texte pendant la saisie
  • OFF : la saisie manuelle est prioritaire

Pour l’animation d’événements ou les traductions importantes, il est recommandé de désactiver cette option et d’utiliser la saisie manuelle.

🤖 Traduction avec ChatGPT

Le mode ChatGPT permet des traductions plus naturelles et adaptées à la conversation.

  • Formulations plus douces
  • Phrases courtes adaptées à VRChat
  • Ajustement naturel du ton

Une clé API OpenAI est nécessaire. La traduction ChatGPT est facturée selon l’utilisation.

💰 À propos de la facturation OpenAI API

  • L’API OpenAI fonctionne avec une tarification à l’usage
  • Vous êtes facturé uniquement selon votre utilisation
  • Si le paiement à l’usage est activé, les frais peuvent continuer selon l’utilisation
  • Il est recommandé de définir une limite d’utilisation
  • Une limite d’environ 5 à 10 dollars est un bon point de départ
  • Avec 10 dollars, environ 100 000 à 300 000 traductions de phrases courtes sont possibles, selon la longueur du texte

🚫 Fonction de liste noire

La reconnaissance vocale peut parfois afficher un texte que vous n’avez pas prononcé. En ajoutant ce texte à la liste noire, vous pouvez réduire les répétitions de la même erreur.

💻 Configuration requise

  • Windows
  • VRChat version PC
  • OSC activé
  • Microphone
  • Connexion Internet

Ne fonctionne pas sur Quest en mode autonome.

⚠️ Remarques importantes

  • La traduction ChatGPT est payante à l’usage
  • Les modèles Whisper peuvent nécessiter un téléchargement au premier lancement
  • Les modèles de haute précision utilisent davantage les ressources du PC
  • Il est recommandé de modifier les paramètres lorsque l’application est arrêtée

🔄 Mise à jour
