VRC Misa Translator

Outil de traduction en temps réel pour VRChat

Traduit la voix ou le texte, puis envoie automatiquement le résultat dans le Chatbox de VRChat.
Une application de bureau conçue pour faciliter les conversations avec des amis internationaux, l’animation d’événements et la communication multilingue.

✨ Fonctionnalités principales

  • Traduction vocale en temps réel
  • Envoi automatique vers le VRChat Chatbox
  • Traduction par saisie de texte
  • Prise en charge de 20 langues
  • Traduction naturelle (mode ChatGPT)
  • Fonction de liste noire pour réduire les erreurs de reconnaissance

▶️ Utilisation de base

Traduction vocale

  1. Lancez l’application
  2. Sélectionnez votre microphone
  3. Définissez la langue d’entrée et la langue cible
  4. Appuyez sur le bouton Start

Traduction par saisie de texte

  1. Saisissez le texte dans le champ « Original » en bas
  2. Appuyez sur Enter pour traduire et envoyer

Enter : envoyer
Shift + Enter : nouvelle ligne

🤖 Traduction naturelle (mode ChatGPT)

Fournit une traduction plus naturelle et un ajustement du style.

  • Formulations plus douces
  • Phrases courtes adaptées à la conversation
  • Ajustement naturel des nuances

Une clé API OpenAI est nécessaire. La facturation dépend de l’utilisation.

🧹 Fonction de liste noire

La reconnaissance vocale peut parfois afficher du texte qui n’a pas réellement été prononcé.
Par exemple : phrases de fin de vidéo, bruit ou texte mal reconnu.

Le texte ajouté à la liste noire ne sera plus envoyé automatiquement.

Utilisation

  • Utilisez le bouton « Envoyer le texte source vers la liste noire » pour l’ajouter en un clic
  • Modifiez manuellement dans les paramètres avancés, puis cliquez sur « Mettre à jour la liste noire » pour enregistrer

Notes

  • Trop d’entrées peuvent aussi filtrer des conversations normales
  • Il est recommandé d’enregistrer de courtes phrases

💻 Configuration requise

  • Windows
  • VRChat version PC
  • OSC activé
  • Microphone
  • Connexion Internet

Ne fonctionne pas sur Quest en mode autonome.
