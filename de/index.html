✨ VRC Misa Translator v1.10.8

Echtzeit-Übersetzungstool für VRChat

VRC Misa Translator ist eine Desktop-App, die Spracheingaben oder manuell eingegebenen Text übersetzt und an die VRChat Chatbox sendet.

Sie hilft bei Gesprächen mit internationalen Nutzern, bei Events und bei mehrsprachiger Kommunikation.

🚀 Hauptfunktionen

🎤 Sprachübersetzung

  • Echtzeit-Spracherkennung mit Whisper
  • Unterstützt 20 Sprachen
  • Google Translate / ChatGPT-Übersetzungsmodus
  • Auswahl von leichten bis hochpräzisen Modellen

⌨️ Textübersetzung per Eingabe

  • Direkte Eingabe in das Originaltextfeld
  • Enter zum Übersetzen und Senden
  • Shift + Enter für einen Zeilenumbruch
  • Automatisches Leeren nach dem Senden
  • Stiftsymbol bei manueller Texteingabe

📡 VRChat-Integration

  • Senden an die VRChat Chatbox über OSC
  • Automatisches Senden wird unterstützt
  • Unterstützung für mehrsprachige Kommunikation

⚙️ UI und praktische Funktionen

  • Voreinstellungen: Standard / Schnell / Hohe Qualität
  • Mikrofonliste aktualisieren

  • Derzeit verfügbare UI-Sprachen: Japanisch / Englisch
  • README-Schaltfläche

▶️ Grundlegende Verwendung

Sprachübersetzung

  1. App starten
  2. Mikrofon auswählen
  3. Eingabesprache und Zielsprache festlegen
  4. Start drücken

Wenn du sprichst, wird der übersetzte Text automatisch an die VRChat Chatbox gesendet.

Texteingabe

  1. Text in das Originaltextfeld eingeben
  2. Enter drücken, um zu übersetzen und zu senden

Enter = Senden
Shift + Enter = Neue Zeile

🎤 Priorität zwischen Sprache und manueller Eingabe

In den erweiterten Einstellungen kannst du festlegen, ob Spracheingabe oder manuelle Texteingabe Vorrang hat.

  • ON: Sprache kann den eingegebenen Text während der Eingabe überschreiben
  • OFF: Manuelle Eingabe hat Vorrang

Für Event-Moderation oder besonders genaue Übersetzungen wird empfohlen, diese Option auszuschalten und manuell einzugeben.

🤖 ChatGPT-Übersetzung

Der ChatGPT-Modus ermöglicht natürlichere und gesprächsfreundlichere Übersetzungen.

  • Weichere Formulierungen
  • Kurze, VRChat-taugliche Sätze
  • Natürlichere Tonanpassung

Ein OpenAI API Key ist erforderlich. Die ChatGPT-Übersetzung wird nutzungsbasiert abgerechnet.

💰 OpenAI API-Abrechnung

  • Die OpenAI API wird nutzungsbasiert abgerechnet
  • Es entstehen nur Kosten für die tatsächliche Nutzung
  • Wenn Pay-as-you-go aktiviert ist, können je nach Nutzung fortlaufend Kosten entstehen
  • Zur Kostenkontrolle wird empfohlen, ein Nutzungslimit festzulegen
  • Ein Limit von etwa 5 bis 10 US-Dollar ist ein sicherer Startwert
  • Mit 10 US-Dollar sind je nach Textlänge ungefähr 100.000 bis 300.000 kurze Übersetzungen möglich

🚫 Blacklist-Funktion

Die Spracherkennung kann manchmal Text anzeigen, den du nicht gesagt hast. Wenn du diesen Text zur Blacklist hinzufügst, kann dieselbe Fehl-Erkennung künftig reduziert werden.

💻 Systemanforderungen

  • Windows
  • VRChat PC-Version
  • OSC aktiviert
  • Mikrofon
  • Internetverbindung

Funktioniert nicht auf Quest im Standalone-Modus.

⚠️ Hinweise

  • ChatGPT-Übersetzung ist kostenpflichtig nach Nutzung
  • Whisper-Modelle müssen beim ersten Mal möglicherweise heruntergeladen werden
  • Hochpräzise Modelle benötigen mehr PC-Leistung
  • Es wird empfohlen, Einstellungen nur im gestoppten Zustand zu ändern

🔄 Updates

Updates werden derzeit manuell durchgeführt.

  • ZIP-Version: Dateien überschreiben
  • Installer-Version: Neueste Version erneut installieren

Die neueste Version kann über die Download-Seite oder den Update-Button in der App geprüft werden.
