VRC Misa Translator

أداة ترجمة فورية لـ VRChat.

تقوم بترجمة صوتك أو النص الذي تكتبه، ثم ترسله تلقائيًا إلى Chatbox في VRChat. مما يجعل التواصل مع الأصدقاء من مختلف الدول أكثر طبيعية.

✨ الميزات الرئيسية

  • ترجمة صوتية فورية
  • إرسال تلقائي إلى VRChat Chatbox
  • الترجمة عبر إدخال النص
  • دعم لعدة لغات
  • وضع الترجمة باستخدام ChatGPT
  • ميزة القائمة السوداء لتقليل التعرف الخاطئ

🆕 أحدث التحسينات

تحسينات عملية

  • تحسين المحتوى الافتراضي للقائمة السوداء
  • إصلاح الأخطاء البسيطة
  • تحسين الاستقرار العام

▶️ طريقة الاستخدام الأساسية

الترجمة الصوتية

  1. شغّل التطبيق
  2. اختر الميكروفون
  3. حدد لغة الإدخال ولغة الترجمة
  4. اضغط “ابدأ”

عند التحدث، سيتم ترجمة النص تلقائيًا وإرساله إلى VRChat Chatbox.

الترجمة بإدخال النص

  1. اكتب في خانة “النص الأصلي” في الأسفل
  2. اضغط Enter للترجمة والإرسال

Enter: إرسال
Shift + Enter: سطر جديد

🎤 أولوية الصوت والإدخال اليدوي

من خلال خيار “الاستبدال بالصوت أثناء كتابة النص” في الإعدادات المتقدمة، يمكنك تغيير أولوية الإدخال بين الصوت والكتابة اليدوية.

  • ON: يتم تطبيق الإدخال الصوتي حتى أثناء الكتابة
  • OFF: أثناء الكتابة يتم تجاهل الصوت وتكون الأولوية للإدخال اليدوي

إذا كنت بحاجة إلى ترجمة دقيقة، مثل إدارة فعالية، فمن المستحسن إيقاف الاستبدال بالصوت واستخدام الإدخال اليدوي.

🤖 حول ترجمة ChatGPT

يتيح وضع ترجمة ChatGPT إنشاء جمل أكثر طبيعية في المحادثة.

  • تعبيرات أكثر لطفًا
  • جمل قصيرة مناسبة للمحادثة
  • تعديل طبيعي للمعاني والنبرة

يتطلب مفتاح OpenAI API. ترجمة ChatGPT تعتمد على الدفع حسب الاستخدام.

💰 رسوم OpenAI API

  • يتم احتساب رسوم OpenAI API حسب الاستخدام
  • تدفع فقط مقابل ما تستخدمه
  • إذا كان Pay-as-you-go مفعّلًا، ستستمر الرسوم حسب الاستخدام
  • يُنصح بتعيين حد استخدام لتجنب الإفراط
  • يُعد حد 5–10 دولارات خيارًا آمنًا
  • يمكن لـ 10 دولارات ترجمة حوالي 100,000 إلى 300,000 جملة محادثة عادية

🚫 ميزة القائمة السوداء

أحيانًا قد يعرض التعرف الصوتي جملًا لم تقلها. بإضافة هذه الجمل إلى القائمة السوداء، ستقل احتمالية إرسالها لاحقًا.

💻 متطلبات التشغيل

  • Windows
  • VRChat (نسخة PC)
  • تفعيل OSC
  • ميكروفون
  • اتصال بالإنترنت

لا يعمل على Quest المستقل فقط.
