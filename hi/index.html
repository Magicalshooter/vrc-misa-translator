  • VRChat Chatbox में स्वतः भेजना
  • टेक्स्ट इनपुट द्वारा अनुवाद
  • कई भाषाओं का समर्थन
  • ChatGPT अनुवाद मोड
  • गलत पहचान कम करने के लिए ब्लैकलिस्ट सुविधा

🆕 नवीनतम सुधार

व्यावहारिक सुधार

  • ब्लैकलिस्ट की प्रारंभिक सामग्री बेहतर की गई
  • छोटी समस्याएँ ठीक की गईं
  • कुल स्थिरता में सुधार

▶️ मूल उपयोग

वॉइस अनुवाद

  1. ऐप शुरू करें
  2. माइक्रोफ़ोन चुनें
  3. इनपुट भाषा और अनुवाद भाषा सेट करें
  4. “शुरू करें” दबाएँ

बोलते ही टेक्स्ट स्वतः अनुवाद होकर VRChat Chatbox में भेज दिया जाएगा।

टेक्स्ट इनपुट अनुवाद

  1. नीचे “मूल पाठ” बॉक्स में लिखें
  2. अनुवाद और भेजने के लिए Enter दबाएँ

Enter: भेजें
Shift + Enter: नई पंक्ति

🎤 आवाज़ और मैनुअल इनपुट की प्राथमिकता

उन्नत सेटिंग्स में “टेक्स्ट लिखते समय आवाज़ से ओवरराइट” विकल्प से आवाज़ इनपुट और मैनुअल इनपुट की प्राथमिकता बदली जा सकती है।

  • ON: टाइप करते समय भी आवाज़ इनपुट लागू होगा
  • OFF: टाइप करते समय आवाज़ अनदेखी होगी, मैनुअल इनपुट प्राथमिक होगा

यदि सटीक अनुवाद चाहिए, जैसे कार्यक्रम संचालन के समय, तो आवाज़ ओवरराइट बंद करके मैनुअल इनपुट उपयोग करें।

🤖 ChatGPT अनुवाद के बारे में

ChatGPT अनुवाद मोड अधिक प्राकृतिक वार्तालाप शैली देता है।

  • नरम और स्वाभाविक अभिव्यक्ति
  • बातचीत के लिए छोटे वाक्य
  • भाव और अर्थ का प्राकृतिक समायोजन

OpenAI API Key आवश्यक है। ChatGPT अनुवाद उपयोग के अनुसार शुल्क आधारित है।

💰 OpenAI API शुल्क

  • OpenAI API उपयोग के अनुसार शुल्क लेता है
  • आप केवल उपयोग की गई मात्रा के लिए भुगतान करते हैं
  • यदि Pay-as-you-go चालू है, तो उपयोग के अनुसार शुल्क जारी रहेगा
  • अत्यधिक उपयोग रोकने के लिए Usage limit सेट करने की सलाह दी जाती है
  • लगभग 5–10 USD सीमा सुरक्षित मानी जाती है
  • 10 USD में लगभग 100,000–300,000 सामान्य वार्तालाप अनुवाद संभव हैं
