VRChat के लिए रियल-टाइम अनुवाद टूल

आवाज़ या टेक्स्ट का अनुवाद करता है और परिणाम को VRChat Chatbox में स्वतः भेजता है।
यह एक डेस्कटॉप ऐप है जो अंतरराष्ट्रीय दोस्तों के साथ बातचीत, इवेंट संचालन और बहुभाषी संचार को आसान बनाता है।

✨ मुख्य विशेषताएँ

  • रियल-टाइम वॉइस ट्रांसलेशन
  • VRChat Chatbox में स्वतः भेजना
  • टेक्स्ट इनपुट ट्रांसलेशन
  • 20 भाषाओं का समर्थन
  • प्राकृतिक अनुवाद (ChatGPT मोड)
  • गलत पहचान कम करने के लिए ब्लैकलिस्ट सुविधा

🆕 v1.9.26 → v1.11.1 अपडेट

✨ नई सुविधाएँ

  • “मूल टेक्स्ट को ब्लैकलिस्ट में भेजें” एक-क्लिक फीचर जोड़ा गया
  • प्राकृतिक अनुवाद (ChatGPT मोड) में सुधार
  • मल्टी-लैंग्वेज टूलटिप समर्थन जोड़ा गया

🧹 ब्लैकलिस्ट सुधार

  • ब्लैकलिस्ट एडिटिंग को “अपडेट सिस्टम” में बदला गया (अधिक सुरक्षित)
  • डिफ़ॉल्ट ब्लैकलिस्ट सामग्री को बेहतर बनाया गया
  • गलत पहचान और नॉइज़ आउटपुट फ़िल्टरिंग में सुधार

🌍 UI और बहुभाषी समर्थन

  • UI अब 5 भाषाओं का समर्थन करता है: जापानी / अंग्रेज़ी / चीनी (सरलीकृत) / चीनी (पारंपरिक) / कोरियाई
  • License और Guide विंडो के मल्टी-लैंग्वेज लिंक को ठीक किया गया
  • UI भाषा बदलने की स्थिरता में सुधार

🎨 UI सुधार

  • ऊपरी मेनू का पुनर्गठन
  • README / Update / License की स्थिति में सुधार
  • इनपुट UI और उपयोग प्रवाह में सुधार
  • टूलटिप प्रदर्शन में सुधार

⚙️ स्थिरता और आंतरिक सुधार

  • छोटे बग फिक्स
  • कुल स्थिरता में सुधार
  • अनुवाद प्रोसेसिंग में सुधार

▶️ उपयोग का तरीका

वॉइस ट्रांसलेशन

  1. ऐप चालू करें
  2. माइक्रोफोन चुनें
  3. इनपुट और लक्ष्य भाषा सेट करें
  4. Start बटन दबाएँ

टेक्स्ट ट्रांसलेशन

  1. नीचे “Original” फ़ील्ड में टेक्स्ट दर्ज करें
  2. Enter दबाकर अनुवाद और भेजें

Enter: भेजें
Shift + Enter: नई पंक्ति

🤖 प्राकृतिक अनुवाद (ChatGPT मोड)

अधिक प्राकृतिक अनुवाद और टोन समायोजन प्रदान करता है।

  • नरम अभिव्यक्ति
  • बातचीत के लिए उपयुक्त छोटे वाक्य
  • स्वाभाविक अर्थ समायोजन

OpenAI API Key आवश्यक है। उपयोग के आधार पर शुल्क लिया जाता है।

🧹 ब्लैकलिस्ट सुविधा

वॉइस पहचान कभी-कभी ऐसा टेक्स्ट दिखा सकती है जो वास्तव में बोला नहीं गया था।
जैसे वीडियो समाप्ति वाक्य, नॉइज़ या गलत पहचान।

ब्लैकलिस्ट में जोड़े गए टेक्स्ट को अब स्वतः नहीं भेजा जाएगा।

उपयोग

  • “मूल टेक्स्ट को ब्लैकलिस्ट में भेजें” बटन से तुरंत जोड़ें
  • Advanced Settings में संपादन करें और “ब्लैकलिस्ट अपडेट” दबाकर सहेजें

ध्यान दें

  • बहुत अधिक एंट्री सामान्य बातचीत को भी फ़िल्टर कर सकती हैं
  • छोटे वाक्यांश जोड़ना बेहतर है

💻 सिस्टम आवश्यकताएँ

  • Windows
  • VRChat (PC संस्करण)
  • OSC सक्षम
  • माइक्रोफोन
  • इंटरनेट कनेक्शन

Quest स्टैंडअलोन मोड में काम नहीं करता।
