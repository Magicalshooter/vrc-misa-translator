VRC Misa Translator

Инструмент перевода в реальном времени для VRChat.

Переводит вашу речь или текст и автоматически отправляет результат в Chatbox VRChat. Помогает сделать общение с друзьями из других стран более естественным.

✨ Основные функции

  • Голосовой перевод в реальном времени
  • Автоматическая отправка в VRChat Chatbox
  • Перевод введённого текста
  • Поддержка множества языков
  • Режим перевода с ChatGPT
  • Чёрный список для уменьшения ложного распознавания

▶️ Основное использование

Голосовой перевод

  1. Запустите приложение
  2. Выберите микрофон
  3. Установите язык ввода и язык перевода
  4. Нажмите «Старт»

Когда вы говорите, текст автоматически переводится и отправляется в VRChat Chatbox.

Перевод текста

  1. Введите текст в поле «Оригинальный текст» внизу
  2. Нажмите Enter для перевода и отправки

Enter: отправить
Shift + Enter: новая строка

🎤 Приоритет голоса и ручного ввода

В расширенных настройках можно изменить приоритет между голосовым вводом и ручным вводом через параметр «Перезаписывать текст голосом во время ввода».

  • ON: голосовой ввод будет применяться даже во время печати
  • OFF: во время ручного ввода голос игнорируется, приоритет у текста

Если нужна точная передача текста, например при ведении мероприятия, рекомендуется выключить перезапись голосом и использовать ручной ввод.

🤖 О переводе ChatGPT

Режим перевода ChatGPT позволяет получать более естественные разговорные фразы.

  • Более мягкие формулировки
  • Короткие фразы для общения
  • Естественная передача нюансов

Требуется API-ключ OpenAI. Перевод ChatGPT оплачивается по использованию.

💰 Оплата OpenAI API

  • OpenAI API использует оплату по факту использования
  • Вы платите только за использованный объём
  • Если включён Pay-as-you-go, списания продолжаются по мере использования
  • Рекомендуется установить лимит использования
  • Для безопасности подойдёт лимит около 5–10 долларов
  • 10 долларов хватит примерно на 100 000–300 000 обычных переводов

🚫 Чёрный список

Иногда распознавание речи может выводить текст, который вы не произносили. Добавьте такие фразы в чёрный список, чтобы они реже отправлялись.
