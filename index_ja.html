🚀 Free版 / Pro版について

VRC Misa Translator は Free版と Pro版の2種類を用意しています。

Free版

  • CPU動作
  • 基本機能をすべて利用可能
  • 手動アップデート

Pro版

  • GPU対応Whisperを利用可能
  • large-v3-turbo などの高性能モデルを利用可能
  • 高速な音声認識
  • オートアップデート対応

※翻訳機能や基本機能は Free版 / Pro版 共通です。
※主な違いは GPU対応とオートアップデート機能です。

▶️ 基本的な使い方

音声翻訳

  1. アプリを起動
  2. マイクを選択
  3. 入力言語・翻訳先を設定
  4. 必要に応じて翻訳エンジンを選択
  5. 開始ボタンを押す
  6. 話すと自動で翻訳され、VRChat Chatboxへ送信されます

テキスト入力翻訳

  1. 下部「原文」欄へ入力
  2. Enterで翻訳＆送信

Enter：送信
Shift + Enter：改行

🎚️ 音声キャリブレーション

VRC Misa Translatorでは、使用環境に合わせて音声認識の感度を自動調整する 「音声キャリブレーション」機能を搭載しています。

部屋の環境音と実際の話し声を測定し、 音声認識の開始しきい値・終了しきい値・無音終了時間を自動設定します。

キャリブレーションの手順

  1. 「音声キャリブレーション」を実行します
  2. 最初に環境ノイズを数秒間測定します
  3. 続いて、普段VRChatで話す音量と距離でサンプル文章を読み上げます
  4. 測定結果から最適なしきい値が自動設定されます

自動調整される項目

  • 音声認識開始しきい値
  • 音声認識終了しきい値
  • 無音終了時間

こんな時におすすめ

  • 初めて使用する時
  • マイクを変更した時
  • 音声が認識されにくい時
  • 無音なのに誤認識が発生する時
  • 部屋の環境音が変わった時

音声データそのものは保存されません。
測定結果のみが設定として保存されます。

🤖 自然な翻訳（ChatGPTモード）

ChatGPTを使用することで、より自然な翻訳や文体調整を行えます。

  • 柔らかい言い回し
  • 会話向けの自然な短文
  • 丁寧語・ニュアンスの調整
  • 原文重視の翻訳

OpenAI APIキーが必要です。
ChatGPT翻訳は従量課金制です。使用量にご注意ください。

ChatGPTを使わない場合でも、Google翻訳で通常利用できます。

🧹 ブラックリスト / セーフリスト機能

ブラックリスト

音声認識では、実際に話していない文章が表示されることがあります。
例：動画の締め文、ノイズ、誤認識など。

ブラックリストに登録した文章は、自動送信されなくなります。

  • 「不自然な認識結果をブラックリストへ送る」ボタンでワンクリック登録
  • 詳細設定で手動編集
  • 編集後は「ブラックリスト更新」で保存

セーフリスト

セーフリストに登録した言葉は、不自然判定されても送信されます。
「ぱちぱちぱち」「www」「固有名詞」など、短くても自然な表現を守るのに便利です。

注意

  • ブラックリストに登録しすぎると、通常の会話も除外される場合があります
  • 迷った場合は、短いフレーズ単位で登録するのがおすすめです

🪟 原文Overlayについて

Whisperが認識した原文を別ウィンドウに表示できます。
Desktop+ や XSOverlay などを利用することで、VRChat中でも認識結果を確認できます。

  • 認識結果をVR内で確認可能
  • 透明度調整対応
  • 音声認識ON/OFF操作対応
  • VR中の翻訳不安を軽減
