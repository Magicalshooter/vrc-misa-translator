🚀 About the Free and Pro Editions

VRC Misa Translator is available in two editions: Free and Pro.

Free Edition

  • Runs on CPU
  • Includes all basic features
  • Manual updates

Pro Edition

  • Supports GPU-powered Whisper
  • Can use high-performance models such as large-v3-turbo
  • Faster speech recognition
  • Supports automatic updates

Translation features and basic functions are shared by both the Free and Pro editions.
The main differences are GPU support and automatic update support.

▶️ Basic Usage

Voice Translation

  1. Launch the application.
  2. Select your microphone.
  3. Set the input language and target translation language.
  4. Select a translation engine if needed.
  5. Press the Start button.
  6. When you speak, your voice will be translated automatically and sent to the VRChat Chatbox.

Text Input Translation

  1. Enter text in the Original Text field at the bottom.
  2. Press Enter to translate and send.

Enter: Send
Shift + Enter: New line

🎚️ Voice Calibration

VRC Misa Translator includes a Voice Calibration feature that automatically adjusts speech recognition sensitivity to match your environment and microphone.

The calibration process measures both ambient noise and your actual speaking voice, then automatically configures the speech recognition start threshold, end threshold, and silence timeout.

How to Calibrate

  1. Run Voice Calibration.
  2. The application first measures environmental noise for a few seconds.
  3. Next, read the sample sentence using the same speaking volume and microphone distance you normally use in VRChat.
  4. The optimal thresholds are calculated and applied automatically.

Automatically Adjusted Settings

  • Speech recognition start threshold
  • Speech recognition end threshold
  • Silence timeout

Recommended When

  • Using the application for the first time
  • Changing your microphone
  • Speech is difficult to detect
  • False recognition occurs during silence
  • Your room's background noise changes

Audio data itself is not saved.
Only the calculated calibration settings are saved.

🧹 Blacklist / Safelist Features

Blacklist

Speech recognition may sometimes display text that you did not actually say.
Examples include video outro phrases, noise, or incorrect recognition results.

Text registered in the blacklist will no longer be sent automatically.

  • Register with one click using the Send Unnatural Recognition Result to Blacklist button
  • Edit manually from the advanced settings
  • After editing, save with Update Blacklist

Safelist

Words registered in the safelist will still be sent even if they are detected as unnatural.
This is useful for protecting short but natural expressions such as applause sounds, "lol", or proper nouns.

Notes

  • If you add too many items to the blacklist, normal conversations may also be filtered out
  • When unsure, it is recommended to register short phrases rather than long sentences
