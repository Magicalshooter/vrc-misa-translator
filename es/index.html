VRC Misa Translator

Herramienta de traducción en tiempo real para VRChat

Traduce voz o texto y envía automáticamente el resultado al Chatbox de VRChat.
Una aplicación de escritorio diseñada para conversar con amigos internacionales, organizar eventos y comunicarse en varios idiomas con mayor comodidad.

✨ Funciones principales

  • Traducción de voz en tiempo real
  • Envío automático al Chatbox de VRChat
  • Traducción mediante entrada de texto
  • Compatible con 20 idiomas
  • Traducción natural (modo ChatGPT)
  • Función de lista negra para reducir errores de reconocimiento

▶️ Uso básico

Traducción de voz

  1. Inicia la aplicación
  2. Selecciona el micrófono
  3. Configura el idioma de entrada y el idioma de destino
  4. Presiona el botón Start

Traducción por texto

  1. Escribe el texto en el campo “Original” inferior
  2. Presiona Enter para traducir y enviar

Enter: enviar
Shift + Enter: nueva línea

🤖 Traducción natural (modo ChatGPT)

Proporciona una traducción más natural y ajuste de tono.

  • Expresiones más suaves
  • Frases cortas adecuadas para conversación
  • Ajuste natural de matices

Se requiere una clave API de OpenAI. Se aplican cargos según el uso.

🧹 Función de lista negra

El reconocimiento de voz puede mostrar texto que en realidad no se dijo.
Por ejemplo: frases típicas de cierre de videos, ruido o texto mal reconocido.

El texto añadido a la lista negra ya no se enviará automáticamente.

Uso

  • Usa el botón “Enviar texto original a la lista negra” para registrarlo con un clic
  • Edita manualmente en Configuración avanzada y luego presiona “Actualizar lista negra” para guardar

Notas

  • Demasiadas entradas pueden filtrar también conversaciones normales
  • Se recomienda registrar frases cortas
