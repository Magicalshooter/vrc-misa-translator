✨ VRC Misa Translator v1.10.8

Herramienta de traducción en tiempo real para VRChat

VRC Misa Translator es una aplicación de escritorio que traduce voz o texto escrito manualmente y lo envía al Chatbox de VRChat.

Está diseñada para facilitar conversaciones con usuarios internacionales, eventos y comunicación multilingüe.

Volver a la página principal

🚀 Funciones principales

🎤 Traducción por voz

  • Reconocimiento de voz en tiempo real con Whisper
  • Compatible con 20 idiomas
  • Modo Google Translate / traducción con ChatGPT
  • Elección entre modelos ligeros y de alta precisión

⌨️ Traducción por texto

  • Escribe directamente en el campo de texto original
  • Enter para traducir y enviar
  • Shift + Enter para salto de línea
  • Limpieza automática después del envío
  • Ícono de lápiz al usar entrada manual

📡 Integración con VRChat

  • Envío al Chatbox de VRChat mediante OSC
  • Compatible con envío automático
  • Ayuda para comunicación multilingüe

⚙️ Interfaz y funciones útiles

  • Preajustes: estándar / rápido / alta calidad
  • Actualizar lista de micrófonos
  • Función de lista negra para errores de reconocimiento

  • Idiomas de interfaz disponibles actualmente: japonés / inglés
  • Botón README

💰 Gestión de uso de ChatGPT

▶️ Uso básico

Traducción por voz

  1. Inicia la aplicación
  2. Selecciona el micrófono
  3. Elige idioma de entrada y de destino
  4. Pulsa Iniciar

Cuando hables, el texto traducido se enviará automáticamente al Chatbox de VRChat.

Entrada de texto

  1. Escribe texto en el campo original
  2. Pulsa Enter para traducir y enviar

Enter = Enviar
Shift + Enter = Nueva línea

🎤 Prioridad entre voz y texto manual

En la configuración avanzada puedes elegir la prioridad entre voz y texto escrito manualmente.

  • ON: la voz puede sobrescribir el texto mientras escribes
  • OFF: la entrada manual tiene prioridad

Para eventos o traducciones importantes se recomienda OFF y usar texto manual.

🤖 Traducción con ChatGPT

El modo ChatGPT ofrece traducciones más naturales y adecuadas para conversación.

  • Expresiones más suaves
  • Frases cortas ideales para VRChat
  • Ajuste natural del tono

Se requiere una clave API de OpenAI. La traducción con ChatGPT tiene costo según uso.

💰 Facturación de OpenAI API

  • La API de OpenAI funciona con pago por uso
  • Solo pagas por lo que utilizas
  • Si Pay-as-you-go está activado, seguirá cobrando según uso
  • Se recomienda configurar un límite de uso
  • Un límite de 5 a 10 USD es una buena referencia
  • Con 10 USD se pueden hacer aproximadamente 100,000 a 300,000 traducciones cortas según longitud

🚫 Función de lista negra

A veces el reconocimiento de voz muestra texto que no dijiste. Si lo añades a la lista negra, se reducirá ese mismo error en el futuro.

💻 Requisitos del sistema

  • Windows
  • VRChat versión PC
  • OSC activado
  • Micrófono
  • Conexión a Internet

No funciona en Quest en modo independiente.

⚠️ Avisos importantes

  • La traducción con ChatGPT tiene costo según uso
  • Los modelos Whisper pueden requerir descarga inicial
  • Los modelos de alta precisión consumen más recursos
  • Se recomienda cambiar ajustes con la app detenida
