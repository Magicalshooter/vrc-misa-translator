VRC Misa Translator

VRChat向けリアルタイム翻訳ツール

音声やテキストを翻訳し、VRChat Chatboxへ自動送信します。
海外フレンドとの会話、イベント進行、多言語交流を快適にするデスクトップアプリです。

✨ 主な機能

  • リアルタイム音声翻訳
  • VRChat Chatboxへ自動送信
  • テキスト入力翻訳
  • 20か国語対応
  • ChatGPT翻訳モード
  • 誤認識を減らすブラックリスト機能

▶️ 基本的な使い方

音声翻訳

  1. アプリを起動
  2. マイクを選択
  3. 入力言語・翻訳先を設定
  4. 開始ボタンを押す

テキスト入力翻訳

  1. 下部「原文」欄へ入力
  2. Enterで翻訳＆送信

Enter：送信
Shift + Enter：改行

🤖 ChatGPT翻訳について

ChatGPT翻訳モードを使うと、より自然な会話文にできます。

  • 柔らかい言い回し
  • 会話向け短文
  • 自然なニュアンス調整

OpenAI APIキーが必要です。ChatGPT翻訳は従量課金制です。

💻 動作環境

  • Windows
  • VRChat（PC版）
  • OSC有効
  • マイク
  • インターネット接続

Quest単体では動作しません。
