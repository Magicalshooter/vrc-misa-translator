VRC Misa Translator

Strumento di traduzione in tempo reale per VRChat

Traduce voce o testo e invia automaticamente il risultato alla Chatbox di VRChat.
Un’applicazione desktop pensata per facilitare la comunicazione con amici internazionali, eventi e conversazioni multilingue.

✨ Funzionalità principali

  • Traduzione vocale in tempo reale
  • Invio automatico alla Chatbox di VRChat
  • Traduzione tramite input di testo
  • Supporta 20 lingue
  • Traduzione naturale (modalità ChatGPT)
  • Funzione blacklist per ridurre gli errori di riconoscimento

▶️ Utilizzo di base

Traduzione vocale

  1. Avvia l’applicazione
  2. Seleziona il microfono
  3. Imposta lingua di input e lingua di destinazione
  4. Premi il pulsante Start

Traduzione testo

  1. Inserisci il testo nel campo “Original” in basso
  2. Premi Enter per tradurre e inviare

Enter: invia
Shift + Enter: nuova riga

🤖 Traduzione naturale (modalità ChatGPT)

Fornisce una traduzione più naturale e regolazione del tono.

  • Espressioni più fluide
  • Frasi brevi adatte alla conversazione
  • Adattamento naturale delle sfumature

È richiesta una chiave API OpenAI. Il costo è basato sull’utilizzo.

🧹 Funzione blacklist

Il riconoscimento vocale può talvolta generare testo che non è stato realmente pronunciato.
Ad esempio: frasi di fine video, rumore o errori di riconoscimento.

Il testo aggiunto alla blacklist non verrà più inviato automaticamente.

Utilizzo

  • Usa il pulsante “Invia testo originale alla blacklist” per aggiungere con un clic
  • Modifica manualmente nelle impostazioni avanzate e premi “Aggiorna blacklist” per salvare

Note

  • Troppe voci possono filtrare anche conversazioni normali
  • Si consiglia di aggiungere frasi brevi

💻 Requisiti di sistema

  • Windows
  • VRChat (versione PC)
  • OSC abilitato
  • Microfono
  • Connessione Internet

Non funziona su Quest in modalità standalone.
