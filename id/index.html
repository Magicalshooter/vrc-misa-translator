▶️ Cara Penggunaan Dasar

Terjemahan Suara

  1. Jalankan aplikasi
  2. Pilih mikrofon
  3. Atur bahasa input dan target
  4. Tekan tombol Start

Terjemahan Teks

  1. Masukkan teks di kolom “Original”
  2. Tekan Enter untuk menerjemahkan dan mengirim

Enter: kirim
Shift + Enter: baris baru

🤖 Terjemahan Alami (Mode ChatGPT)

Memberikan terjemahan yang lebih alami dan penyesuaian gaya bahasa.

  • Ekspresi lebih halus
  • Kalimat pendek yang cocok untuk percakapan
  • Penyesuaian nuansa secara alami

Memerlukan OpenAI API Key. Biaya berdasarkan penggunaan.

🧹 Fitur Blacklist

Pengenalan suara terkadang dapat menghasilkan teks yang sebenarnya tidak diucapkan.
Contoh: kalimat penutup video, noise, atau kesalahan pengenalan.

Teks yang ditambahkan ke blacklist tidak akan dikirim secara otomatis.

Cara Penggunaan

  • Gunakan tombol “Kirim teks asli ke blacklist” untuk menambahkan dengan satu klik
  • Edit secara manual di Advanced Settings lalu tekan “Update Blacklist” untuk menyimpan

Catatan

  • Terlalu banyak entri dapat memfilter percakapan normal
  • Disarankan menggunakan frasa pendek

💻 Persyaratan Sistem

  • Windows
  • VRChat (versi PC)
  • OSC diaktifkan
  • Mikrofon
  • Koneksi internet

Tidak berfungsi di Quest dalam mode standalone.
