VRC Misa Translator

Alat terjemahan real-time untuk VRChat.

Menerjemahkan suara atau teks Anda, lalu mengirimkannya secara otomatis ke Chatbox VRChat. Membantu komunikasi dengan teman dari berbagai negara terasa lebih alami.

✨ Fitur utama

  • Terjemahan suara real-time
  • Pengiriman otomatis ke VRChat Chatbox
  • Terjemahan melalui input teks
  • Dukungan banyak bahasa
  • Mode terjemahan ChatGPT
  • Fitur daftar hitam untuk mengurangi kesalahan pengenalan suara

🆕 Peningkatan terbaru

Peningkatan praktis

  • Isi awal daftar hitam diperkuat
  • Perbaikan bug kecil
  • Peningkatan stabilitas secara keseluruhan

▶️ Cara penggunaan dasar

Terjemahan suara

  1. Jalankan aplikasi
  2. Pilih mikrofon
  3. Atur bahasa input dan bahasa tujuan
  4. Tekan “Mulai”

Saat Anda berbicara, teks akan diterjemahkan otomatis dan dikirim ke VRChat Chatbox.

Terjemahan input teks

  1. Masukkan teks ke kolom “Teks asli” di bagian bawah
  2. Tekan Enter untuk menerjemahkan dan mengirim

Enter: kirim
Shift + Enter: baris baru

🎤 Prioritas antara input suara dan input manual

Dengan opsi “Timpa dengan suara saat input teks” di pengaturan lanjutan, Anda dapat mengubah prioritas antara input suara dan input manual.

  • ON: input suara tetap diterapkan meskipun sedang mengetik
  • OFF: saat mengetik, input suara diabaikan dan input manual diprioritaskan

Jika membutuhkan terjemahan yang akurat, misalnya saat menjadi pembawa acara, sebaiknya matikan penimpaan suara dan gunakan input manual.

🤖 Tentang terjemahan ChatGPT

Dengan mode terjemahan ChatGPT, kalimat percakapan dapat dibuat lebih alami.

  • Ungkapan yang lebih lembut
  • Kalimat pendek yang cocok untuk percakapan
  • Penyesuaian nuansa yang alami

Diperlukan OpenAI API key. Terjemahan ChatGPT dikenakan biaya berdasarkan penggunaan.

💰 Tentang biaya OpenAI API

  • OpenAI API menggunakan sistem biaya berdasarkan penggunaan
  • Biaya hanya dikenakan sesuai jumlah pemakaian
  • Jika Pay-as-you-go aktif, biaya akan terus dikenakan sesuai penggunaan
  • Untuk mencegah penggunaan berlebihan, disarankan mengatur Usage limit
  • Sebagai acuan, batas sekitar 5–10 dolar cukup aman
  • Dengan 10 dolar, kira-kira dapat menerjemahkan 100.000–300.000 kalimat percakapan umum

🚫 Fitur daftar hitam

Pengenalan suara terkadang menampilkan kalimat yang tidak Anda ucapkan. Jika kalimat tersebut didaftarkan ke daftar hitam, kalimat itu akan lebih jarang terkirim.

💻 Lingkungan sistem

  • Windows
  • VRChat versi PC
  • OSC aktif
  • Mikrofon
  • Koneksi internet

Tidak berjalan pada Quest standalone saja.

⚠️ Catatan penting

  • Terjemahan ChatGPT dikenakan biaya berdasarkan penggunaan
  • Model Whisper akan diunduh saat pertama kali digunakan
  • Model akurasi tinggi menggunakan performa PC lebih besar
  • Disarankan mengubah pengaturan saat aplikasi sedang berhenti

🔄 Cara memperbarui
