VRC Misa Translator

Ferramenta de tradução em tempo real para VRChat

Traduz voz ou texto e envia automaticamente o resultado para o VRChat Chatbox.

▶️ Uso básico

Tradução por voz

  1. Inicie o aplicativo
  2. Selecione o microfone
  3. Defina o idioma de entrada e o idioma de destino
  4. Pressione o botão Start

Tradução por texto

  1. Digite o texto no campo “Original” na parte inferior
  2. Pressione Enter para traduzir e enviar

Enter: enviar
Shift + Enter: nova linha

🤖 Tradução natural (modo ChatGPT)

Oferece uma tradução mais natural e ajuste de tom.

  • Expressões mais suaves
  • Frases curtas adequadas para conversas
  • Ajuste natural de nuances

É necessária uma chave API da OpenAI. A cobrança é baseada no uso.

🧹 Função de blacklist

O reconhecimento de voz às vezes pode gerar texto que não foi realmente falado.
Por exemplo: frases de encerramento de vídeo, ruído ou texto reconhecido incorretamente.

O texto adicionado à blacklist não será mais enviado automaticamente.

Como usar

  • Use o botão “Enviar texto original para a blacklist” para adicionar com um clique
  • Edite manualmente em Advanced Settings e pressione “Update Blacklist” para salvar

Observações

  • Muitas entradas podem filtrar também conversas normais
  • Recomenda-se adicionar frases curtas

💻 Requisitos do sistema

  • Windows
  • VRChat (versão PC)
  • OSC ativado
  • Microfone
  • Conexão com a internet

Não funciona no Quest em modo standalone.
