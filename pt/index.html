VRC Misa Translator

Инструмент перевода в реальном времени для VRChat

Переводит речь или текст и автоматически отправляет результат в VRChat Chatbox.
Десктопное приложение для удобного общения с международными друзьями, проведения мероприятий и многоязычных разговоров.

✨ Основные функции

  • Перевод речи в реальном времени
  • Автоматическая отправка в VRChat Chatbox
  • Перевод введённого текста
  • Поддержка 20 языков
  • Естественный перевод (режим ChatGPT)
  • Функция чёрного списка для уменьшения ошибок распознавания

▶️ Основное использование

Перевод речи

  1. Запустите приложение
  2. Выберите микрофон
  3. Установите язык ввода и перевода
  4. Нажмите кнопку Start

Перевод текста

  1. Введите текст в поле «Original» внизу
  2. Нажмите Enter для перевода и отправки

Enter: отправить
Shift + Enter: новая строка

🤖 Естественный перевод (режим ChatGPT)

Обеспечивает более естественный перевод и настройку стиля.

  • Более мягкие формулировки
  • Короткие фразы, подходящие для общения
  • Естественная передача нюансов

Требуется API-ключ OpenAI. Оплата зависит от использования.

🧹 Функция чёрного списка

Распознавание речи иногда может выводить текст, который не был произнесён.
Например: фразы окончания видео, шум или ошибки распознавания.

Текст, добавленный в чёрный список, больше не будет автоматически отправляться.

Использование

  • Используйте кнопку «Отправить исходный текст в чёрный список» для быстрого добавления
  • Редактируйте вручную в Advanced Settings и нажмите «Update Blacklist» для сохранения

Примечания

  • Слишком большое количество записей может фильтровать обычные разговоры
  • Рекомендуется добавлять короткие фразы

💻 Системные требования

  • Windows
  • VRChat (версия для ПК)
  • Включённый OSC
  • Микрофон
  • Подключение к интернету

Не работает на Quest в автономном режиме.
