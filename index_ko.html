▶️ 기본 사용 방법

음성 번역

  1. 앱을 실행합니다
  2. 마이크를 선택합니다
  3. 입력 언어와 번역 대상 언어를 설정합니다
  4. 필요에 따라 번역 엔진을 선택합니다
  5. 시작 버튼을 누릅니다
  6. 말하면 자동으로 번역되어 VRChat Chatbox로 전송됩니다

텍스트 입력 번역

  1. 하단의 “원문” 입력란에 텍스트를 입력합니다
  2. Enter 키로 번역 및 전송합니다

Enter: 전송
Shift + Enter: 줄바꿈

🎚️ 음성 캘리브레이션

VRC Misa Translator에는 사용 환경에 맞춰 음성 인식 감도를 자동으로 조정하는 “음성 캘리브레이션” 기능이 탑재되어 있습니다.

방 안의 환경 소음과 실제 말소리를 측정하여, 음성 인식 시작 임계값, 종료 임계값, 무음 종료 시간을 자동으로 설정합니다.

캘리브레이션 절차

  1. “음성 캘리브레이션”을 실행합니다
  2. 먼저 몇 초 동안 주변 환경 소음을 측정합니다
  3. 이어서 평소 VRChat에서 말하는 음량과 마이크 거리로 샘플 문장을 읽습니다
  4. 측정 결과를 바탕으로 최적의 임계값이 자동 설정됩니다

자동 조정되는 항목

  • 음성 인식 시작 임계값
  • 음성 인식 종료 임계값
  • 무음 종료 시간

이럴 때 실행을 권장합니다

  • 처음 사용할 때
  • 마이크를 변경했을 때
  • 음성이 잘 인식되지 않을 때
  • 무음 상태인데도 오인식이 발생할 때
  • 방의 소음 환경이 크게 바뀌었을 때

음성 데이터 자체는 저장되지 않습니다.
계산된 캘리브레이션 설정만 저장됩니다.

🤖 자연스러운 번역(ChatGPT 모드)

ChatGPT를 사용하면 더 자연스러운 번역과 문체 조정이 가능합니다.

  • 부드러운 표현
  • 대화에 적합한 자연스러운 짧은 문장
  • 존댓말 및 뉘앙스 조정
  • 원문을 중시한 번역

OpenAI API 키가 필요합니다.
ChatGPT 번역은 사용량 기반 과금 방식입니다. 사용량에 주의해 주세요.

ChatGPT를 사용하지 않아도 Google 번역으로 일반적인 이용이 가능합니다.

🧹 블랙리스트 / 세이프리스트 기능

블랙리스트

음성 인식에서는 실제로 말하지 않은 문장이 표시될 수 있습니다.
예: 영상의 마무리 문구, 잡음, 오인식 등.

블랙리스트에 등록한 문장은 자동 전송되지 않습니다.

  • “비정상 인식 결과를 블랙리스트로 보내기” 버튼으로 원클릭 등록
  • 상세 설정에서 수동 편집
  • 편집 후 “블랙리스트 업데이트”로 저장

세이프리스트

세이프리스트에 등록한 단어는 비정상으로 판정되어도 전송됩니다.
“짝짝짝”, “www”, 고유명사처럼 짧아도 자연스러운 표현을 보호하는 데 유용합니다.

주의

  • 블랙리스트를 너무 많이 등록하면 일반 대화도 제외될 수 있습니다
  • 망설여질 때는 짧은 문구 단위로 등록하는 것을 추천합니다

🪟 원문 Overlay 안내

Whisper가 인식한 원문을 별도의 창에 표시할 수 있습니다.
Desktop+ 또는 XSOverlay 등을 사용하면 VRChat 중에도 인식 결과를 확인할 수 있습니다.

  • 인식 결과를 VR 안에서 확인 가능
