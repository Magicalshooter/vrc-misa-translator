▶️ Basic na paggamit

Voice translation

  1. Buksan ang app.
  2. Piliin ang microphone.
  3. I-set ang input language at target language.
  4. Piliin ang translation engine kung kinakailangan.
  5. Pindutin ang start button.
  6. Kapag nagsalita ka, awtomatikong isasalin ang boses mo at ipapadala sa VRChat Chatbox.

Text input translation

  1. Maglagay ng text sa “Original Text” field sa ibaba.
  2. Pindutin ang Enter para isalin at ipadala.

Enter: ipadala
Shift + Enter: bagong linya

🎚️ Voice Calibration

May Voice Calibration feature ang VRC Misa Translator na awtomatikong nag-a-adjust ng voice recognition sensitivity ayon sa iyong environment at microphone.

Sinusukat ng calibration ang ambient noise at ang aktwal mong boses habang nagsasalita. Pagkatapos, awtomatikong ise-set ang speech detection start threshold, end threshold, at silence timeout.

Mga hakbang sa calibration

  1. Buksan ang “Voice Calibration”.
  2. Una, susukatin ng app ang ambient background noise sa loob ng ilang segundo.
  3. Pagkatapos, basahin ang sample sentence gamit ang normal mong VRChat speaking volume at microphone distance.
  4. Kakalkulahin ang optimal thresholds mula sa resulta at awtomatikong ia-apply ang mga ito.

Mga setting na awtomatikong ina-adjust

  • Speech Detection Start Threshold
  • Speech Detection End Threshold
  • Silence Timeout Duration

Kailan magandang mag-calibrate

  • Sa unang paggamit ng app
  • Pagkatapos magpalit ng microphone
  • Kapag hindi stable ang pag-detect ng boses
  • Kapag may false detections kahit tahimik
  • Kapag malaki ang pagbabago ng background noise sa paligid

Hindi sine-save ang audio recordings mismo.
Tanging ang calculated calibration settings lang ang sine-save.

🧹 Blacklist / Safelist features

Blacklist

Sa voice recognition, minsan may lumalabas na text na hindi mo naman talaga sinabi.
Halimbawa: video ending phrases, noise, o misrecognition.

Ang mga text na nakarehistro sa blacklist ay hindi awtomatikong ipapadala.

  • I-register ang unnatural recognition result sa blacklist gamit ang one-click button.
  • Maaaring i-edit nang manual sa advanced settings.
  • Pagkatapos mag-edit, i-save gamit ang “Update Blacklist”.

Safelist

Ang mga salitang nasa safelist ay ipapadala kahit ma-detect bilang unnatural.
Kapaki-pakinabang ito para protektahan ang maiikli pero natural na expressions gaya ng “clap clap”, “www”, o proper nouns.

Paalala

  • Kapag masyadong maraming nakalagay sa blacklist, maaari ring ma-filter ang normal na usapan.
  • Kung hindi sigurado, mas mainam na magrehistro ng maikling phrases kaysa mahahabang sentences.
