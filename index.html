VRC Misa Translator

VRChat用リアルタイム翻訳ツール

VRC Misa Translator は、音声入力やテキスト入力を翻訳し、 VRChat の Chatbox へ送信できるデスクトップアプリです。

README / Guide Download Update Notes

Features

  • 14か国語対応
  • 音声入力翻訳
  • テキスト入力翻訳
  • VRChat Chatbox への OSC 送信
  • ChatGPT翻訳モード対応
  • 使用金額表示・アラート機能
