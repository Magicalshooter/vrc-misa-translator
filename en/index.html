VRC Misa Translator

Real-time Translation Tool for VRChat

Translates speech and text, then automatically sends the result to the VRChat Chatbox.
A desktop app designed for smoother conversations with international friends, event hosting, and multilingual communication.

✨ Main Features

  • Real-time speech translation
  • Automatic sending to VRChat Chatbox
  • Text input translation
  • Supports 20 languages
  • Natural Translation (ChatGPT Mode)
  • Blacklist feature to reduce misrecognition

▶️ Basic Usage

Voice Translation

  1. Launch the app
  2. Select your microphone
  3. Set the input language and target language
  4. Press the Start button

Text Input Translation

  1. Type into the “Original Text” field at the bottom
  2. Press Enter to translate and send

Enter: Send
Shift + Enter: New line

🤖 Natural Translation (ChatGPT Mode)

Provides more natural translation and tone adjustment.

  • Softer phrasing
  • Conversation-friendly short sentences
  • Natural nuance adjustment

An OpenAI API key is required. Usage-based charges apply.

🧹 Blacklist Feature

Speech recognition may sometimes display text that was not actually spoken.
Examples include video-ending phrases, noise, or misrecognized text.

Text added to the blacklist will no longer be sent automatically.

How to Use

  • Use the “Send Original to Blacklist” button for one-click registration
  • Edit manually in Advanced Settings, then press “Update Blacklist” to save

Notes

  • Adding too many entries may also filter normal conversations
  • Registering short phrases is recommended

💻 System Requirements

  • Windows
  • VRChat PC version
  • OSC enabled
  • Microphone
  • Internet connection

It does not work on Quest standalone.
