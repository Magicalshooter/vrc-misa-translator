✨ VRC Misa Translator v1.10.8

Real-time Translation Tool for VRChat

VRC Misa Translator is a desktop application that translates microphone input or manually typed text and sends it to the VRChat Chatbox.

It helps international communication, multilingual events, and smoother conversations with friends around the world.

Back to Top Page

🚀 Main Features

🎤 Voice Translation

  • Real-time speech-to-text with Whisper
  • Supports 14 languages
  • Google Translate / ChatGPT translation modes
  • Selectable lightweight to high-quality models

⌨️ Text Input Translation

  • Type directly into the source text box
  • Press Enter to translate and send
  • Shift + Enter for new line
  • Auto-clear after sending
  • Pencil icon for manual text input

📡 VRChat Integration

  • Sends translated text to VRChat Chatbox via OSC
  • Automatic sending supported
  • Built for multilingual communication

⚙️ UI & Utility Features

  • Presets (Standard / Fast / High Quality)
  • Microphone refresh list
  • Blacklist filter
  • Log viewer & filters
  • UI language switch (Japanese / English)
  • README button
  • Update page button
  • License viewer

💰 ChatGPT Usage Tools

  • Today's cost display
  • Usage history
  • Usage limit alerts

▶️ Basic Usage

  1. Launch the app
  2. Select your microphone
  3. Choose source and target languages
  4. Press Start

Speak into your microphone and translated text will be sent automatically.

Text Input

  1. Type in the source text box
  2. Press Enter to translate and send

Enter = Send
Shift + Enter = New Line

🎤 Voice Override While Typing

In Advanced Settings, you can choose priority between microphone input and manual typing while entering text.

  • ON: Voice input can overwrite typed text
  • OFF: Manual typing has priority

Recommended OFF when hosting events or when accuracy is important.

🤖 ChatGPT Translation

ChatGPT mode can make translations more natural and conversational.

  • Softer expressions
  • Shorter VRChat-friendly phrasing
  • Natural tone adjustments

Requires an OpenAI API key. Usage is pay-as-you-go.

💻 Requirements
