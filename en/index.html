VRC Misa Translator

A real-time translation tool for VRChat

Translate speech or typed text and automatically send it to the VRChat Chatbox.
A desktop app designed to make conversations with international friends, event hosting, and multilingual communication smoother.

✨ Main Features

  • Real-time voice translation
  • Automatic sending to VRChat Chatbox
  • Text input translation
  • Supports 20 languages
  • ChatGPT translation mode
  • Blacklist feature to reduce false recognition

▶️ Basic Usage

Voice Translation

  1. Launch the app
  2. Select your microphone
  3. Set the input language and target language
  4. Press the Start button

Text Input Translation

  1. Type into the “Original Text” field at the bottom
  2. Press Enter to translate and send

Enter: send
Shift + Enter: new line

🤖 About ChatGPT Translation

ChatGPT translation mode can make conversation text sound more natural.

  • Softer wording
  • Short sentences suitable for conversation
  • Natural nuance adjustment

An OpenAI API key is required. ChatGPT translation is billed based on usage.

💻 System Requirements

  • Windows
  • VRChat PC version
  • OSC enabled
  • Microphone
  • Internet connection

It does not work on Quest standalone only.
